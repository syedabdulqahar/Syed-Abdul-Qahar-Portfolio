## 🎯 Quick Start (3 Steps)

### Step 1: Customize Your Info (5 min)

Edit this file with your information:

```
src/data/portfolio.js
```

Just replace the placeholder content with your own:

- Name and title
- About section
- Skills and expertise
- Your projects
- Work experience
- Education
- Certificates
- Social links

### Step 2: Add Your Files (5 min)

1. Place your resume PDF at: `public/resume.pdf`
2. Add project images to: `src/assets/projects/`
3. Done! Everything is automatic

### Step 3: Deploy (5 min)

Choose your platform and deploy:

- **Vercel** (Recommended): `npm install -g vercel && vercel`
- **Netlify**: `npm install -g netlify-cli && netlify deploy`
- **GitHub Pages**: Push to gh-pages branch
- **Any other platform**: Upload the `dist/` folder

## 🐛 Troubleshooting

### Issue: Dev server not loading

**Solution:** Make sure port 5173 is not in use. Restart the server.

### Issue: Styles look weird

**Solution:** Clear browser cache. Hard refresh with Cmd+Shift+R (Mac) or Ctrl+Shift+R (Windows).

### Issue: Images not showing

**Solution:** Place images in `public/` folder or `src/assets/` and use relative paths.

### Issue: Form not working

**Solution:** Email integration is not configured. See DEPLOYMENT_GUIDE.md.
